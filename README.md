<summary>How this card is built</summary>

- The card is an SVG (`dark_mode.svg`) generated by the local `gsy_profilecard` package. Dark mode only (ASCII avatars look poor on a white background).
- The ASCII avatar on the left is baked once by [tools/make_art.py](tools/make_art.py) from the source portrait (`tools/avatar.png`) into `art.json`.
- Right-hand text comes from [profile.toml](profile.toml) — edit that file to change any copy without touching code.
- GitHub stats (repos / stars / followers / commits / LOC) are refreshed daily at 04:17 UTC by [.github/workflows/update.yml](.github/workflows/update.yml), which commits the new SVG back to the repo.

Local usage:

```bash
make install   # pip install -e ".[dev]"
make update    # regenerate dark_mode.svg; needs ACCESS_TOKEN in env or env.txt
make test      # pytest
```

`ACCESS_TOKEN` only needs `read:user` + `public_repo` scopes.
